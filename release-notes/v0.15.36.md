The Claude Code port synced to cursor/plugins c742dd6, pstack 0.15.36.

## Upstream changes since 0.15.32

- `/statechart` gets a compiler. Its scripts are now TypeScript with frontends for the spec, config, TLC trace, and view, an IR, passes, and Mermaid, plain-text, and report backends. Property traces keep qualified action names. The launcher runs on Node 22.18 or later, Bun 1.1.5 or later, or Deno 2. The first real check installs TLC and Java with mise, or reads `TLA2TOOLS` and `JAVA` when they are set.
- `/interrogate` keeps only findings that a run against the real code proves. Its report lists each verified finding with the adversaries that found it, then what each adversary dropped and why.
- Orchestrate is agentic. The coordinator spawns workers with the Agent tool and keeps state in a durable store, and the `scripts/orch` CLI is gone.
- `/arena` never runs its judge on the parent's model, and skips the judge when no other model can run. It drops a seat whose model the Agent tool rejects, and refills to two runners.
- Autopilot-stack is autopilot-full without the merge. It stacks a PR only on a PR it builds on.
- `/ketchup-video` slides are subtitled.
- poteto-mode restates the user's goal in its first message, in each subagent brief, and in each final report. Steering or resuming a running agent also runs in the background. The model fallback chain says when a slug counts as rejected.

## Port-side changes

- `scripts/port-from-cursor.sh` learned the 0.15.36 wording. Orchestrate workers become worktree-isolated subagents verified with the project's `verify-<app>` skill, and its Cursor Project store becomes `~/.claude/orchestrate/<project-slug>/`. Upstream's cross-family arena judge becomes cross-tier, because every model in this port is Claude. With the default pool, an Opus parent gets a `haiku` judge, and any other parent gets `opus`. The leftover check now also flags model families, `composer-` and `cursor-grok` slugs, `Task` in backticks, control skills, Cursor Projects, and cloud VMs.
- CI and `scripts/sync-upstream.sh` run statechart's own `npm test`. The sync script resolves `TMPDIR` first, because the launcher's relative-symlink test misresolves under macOS's symlinked `/var` temp directory.
