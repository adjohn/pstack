The Claude Code port synced to cursor/plugins e73df47, pstack 0.15.32.

## Upstream changes since 0.15.5

- New skills: `/poteto-help`, `/correct`, `/sharpen`, `/in-your-own-words`, `/ketchup`, `/ketchup-video`, `/benchmark-checklist`, `/create-formal-verification-skill`, `/maintain-formal-verification-skill`, and `/statechart` (TLA+ models drawn as Mermaid statecharts, with tests).
- New principle leaf, `principle-explain-the-number`, so there are now 24.
- Defaults move from max to xhigh reasoning. Each spawn now picks its own reasoning level for the job. In this port that is the Agent tool's `effort` parameter, stepped up or down from the session's `effortLevel`.
- Review panels drop to two seats, `opus` and `haiku`, because upstream retired Sol. `reflect tooling` moves to `haiku`.
- `/poteto-mode` runs in the chat that receives it. `poteto-agent` is now only the wrapper for delegates, spawned fresh for each task.
- `/architect` designs resist agent mistakes. `/setup-pstack` offers a formal verification skill after the verification skill.
- Prompts distilled across skills and playbooks. Orchestrate drops Graphite. Autopilot loops catch the operator up with `/ketchup`.
- Fixes: `check-plan.mjs` respects fenced code and matching inline code delimiters. watch-pr paginates review threads, distinguishes fork heads, and caps polling sleeps at the deadline. `worktree-audit.sh` takes `-b <base>` and reads PR state from Origin or `gh`. Orchestrate prefers the active PR over branch history.

## Port-side changes

- `scripts/sync-upstream.sh` runs a whole sync: it snapshots upstream onto `upstream-vendor`, merges it with the conflict policy, runs the port, bumps the manifests, and runs the tests. It exits 3 when there is nothing new.
- `scripts/port-from-cursor.sh` learned the 0.15.32 wording: per-spawn effort, readonly and MCP lines, the transcript layout, `/poteto-help` and the guide pages, Cursor Projects, cloud subagents, and cloud workers, which become worktree-isolated subagents. The fork's PR budget lines are rules now too, so a sync reapplies them instead of losing them in a conflict. The leftover check flags more Cursor text: `.cursor/` paths, Custom Mode, `/visualize`, `/add-plugin`, readonly flags, `Task` spawns, and cloud agents.
- Multi-phase plans use a `<pstack>` plugin-root placeholder in place of `${CLAUDE_PLUGIN_ROOT}`. Claude Code does not set that variable in the Bash tool, so the old `cat` lines ran against `/skills/...`.
- poteto-mode says how to run a bundled skill: Read its `SKILL.md`, because `disable-model-invocation` makes the `Skill` tool refuse most pstack skills.
- CI runs the port check, the poteto-mode tool tests and typecheck, and the statechart tests. A new `release-notes/v<version>.md` on main creates the tag and the GitHub release.
- `pr-size-gate.test.ts` passes on Debian, where `sh` is dash.

Not ported: `skills/make-bot-ui`, `assets/logo.png`, and upstream's `docs/harness/claude-code.md`. That file is a runtime name map for upstream's own Claude Code build. This port rewrites the names in place, so the map would contradict it.

If you ran `/setup-pstack` before this release, rerun it so the panel lines drop `sonnet`.
