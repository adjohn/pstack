The Claude Code port synced to cursor/plugins 2f87c85, pstack 0.15.43.

If you ran `/setup-pstack` before this release, run it again. Your `~/.claude/pstack-models.md` has no `# defaults: 3` line, so `/poteto-mode` reminds you once per session. The rerun drops retired roles, swaps the old `haiku` defaults for the new ones, and keeps every value you chose yourself.

## Upstream changes since 0.15.36

- Model routing is Opus-first. Code, prose, and judgment default to Opus at `xhigh`, and no role runs above `xhigh`. Outside a review panel, Fable runs only when you name it or after two Opus runs of the same brief fail their check. `poteto-agent` pins Opus.
- `/setup-pstack` writes `# defaults: 3` and offers `large`, `medium`, and `small` budgets. The `unlimited` budget is gone, and an old `unlimited` file becomes `large`. It retires the `hardest tasks`, `architect runners`, `how explorer`, `how explainer`, `why investigators`, `why synthesizer`, and both `reflect` roles, leaving nine role lines.
- New `poteto-mode/worker.md`. Every agent `/poteto-mode` starts reads it first, so the operator's rules reach agents that never load a slash command.
- `/why` answers from the record in one pass: the commits and PR discussions behind the target, with other sources when that trail is thin. `/how` is one subagent that explores and explains. `/reflect` is one file with no subagents. `/architect` is a short brief that sends large or contested designs to `/arena`. Their prompt and source reference files are gone.
- Shorter texts for poteto-mode, 14 principle leaves, `/unslop`, `/technical-writing`, and the Opening a PR, Babysit, and Multi-phase plan playbooks. The Orchestrate playbook and `check-plan.mjs` are removed, and program-scale work routes to `/figure-it-out`.
- `/sharpen`'s rewritten prompt asks the agent to prototype any choice an experiment can settle, and leaves product and preference choices to you.
- `/statechart` reports the spec's line and column when SANY cannot parse it. Its charts route an arrow into a parent state through the parent's border, so no arrow crosses the parent's title.

## Port-side changes

- `scripts/port-from-cursor.sh` learned the 0.15.43 wording. Cursor slugs become Claude tiers with the Agent `effort` parameter, stepped from the session's `effortLevel`. Panels run `fable`, `opus`, and `sonnet`, with `sonnet` taking upstream's Gemini seat, one effort step below the session level. The arena judge pool is `opus`, `sonnet`, and the cross-vendor judge becomes cross-tier, with `fable` counting as its own tier. Cursor Projects and `-fast` slugs have no Claude Code counterpart and drop out. The leftover check now also flags `opus-fast`, `-fast` slugs, Gemini slugs, vendor checks, and Project workers.
- The shorter poteto-mode, Opening a PR, and Multi-phase plan texts dropped the port's PR-budget entry points. The rules put them back. `references/pr-budget.md` no longer cites the removed `check-plan.mjs`, and it and the PR-size hook describe stacks by base branch, with Graphite optional.
- Babysit triages every review bot (Bugbot, `/code-review`, or similar), and Opening a PR drops Cursor's built-in PR tool for `gh pr create`.
- `/setup-pstack` is ported by hand. It keeps writing the budget to `effortLevel` in `~/.claude/settings.json`. Its migration treats every earlier port default as a default to replace, including old panel lists, `fable` for judgment, and `sonnet` for bug-fix, perf-issue, and hillclimb, which it names and offers to keep.
- The port script drops rules whose targets upstream deleted (`check-plan.mjs` and the Orchestrate store).
